# es-fluent-cli-helpers

[![Docs](https://docs.rs/es-fluent-cli-helpers/badge.svg)](https://docs.rs/es-fluent-cli-helpers/)
[![Crates.io](https://img.shields.io/crates/v/es-fluent-cli-helpers.svg)](https://crates.io/crates/es-fluent-cli-helpers)

Support library used by the temporary runner that
`es-fluent-cli` builds to collect derive inventory and plan
runner-backed generate, clean, and check operations.

Application developers should use
[`es-fluent-cli`](../es-fluent-cli/README.md). Depend on this crate
only when implementing a compatible runner integration.
