# TypeScript example

This example defines its message contract in `src/lib.rs`, exports typed
descriptors and FTL resources into `generated/`, and formats them in a browser
with `@es-fluent/core`.

```sh
npm run export:i18n --workspace @es-fluent/example-typescript
npm run dev --workspace @es-fluent/example-typescript
```

The hosted build is available from the site's **TypeScript demos** page.
