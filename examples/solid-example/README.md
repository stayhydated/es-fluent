# Solid 2 example

This example exports a Rust-owned message contract and uses it through the
Solid 2.0 RC provider and signals from `@es-fluent/solid`.

```sh
npm run export:i18n --workspace @es-fluent/example-solid
npm run dev --workspace @es-fluent/example-solid
```

The hosted build is available from the site's **TypeScript demos** page.
