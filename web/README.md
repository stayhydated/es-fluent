# Ember & Echo web demo

Ember & Echo is the courtyard contender in the fictional Five Ovens Pizza Cup.
The `/dioxus-example/` route is implemented in `src/pages/dioxus_demo.rs` and
demonstrates the Dioxus localization manager with reactive selection across
`en-US`, `fr-FR`, and `zh-CN`.
